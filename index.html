kobs を入力すると、対応する消失曲線が描画され、50 %／95 %／99 %消失にかかる時間（t50% / t95% / t99%）が算出される。

Enter kobs to draw the corresponding decay curve and obtain the times required for 50 %, 95 % and 99 % loss (t50% / t95% / t99%).

簡易 kobs 計算機Quick kobs estimator

（時間, 残存量）の組を入力すると、ln([C]/[C]0) 対 t の最小二乗回帰から kobs と R2 を求める。
グラフは推定された消失曲線（赤）と入力した実測点（黒丸）。
Enter (time, remaining amount) pairs; kobs is obtained as the slope of ln([C]/[C]0) against t. The plot shows the fitted curve (red) with the entered points (black).

計算過程（検算用）

      

    

  


  

    枠は左上のハンドルをドラッグすると入れ替えられます。ドラッグできない環境では、ハンドルをクリック→移動先のハンドルをクリックでも入れ替わります。列数を変えると枠は自動で折り返します。

    各枠の × は1回目で曲線を消去し、空になった枠でもう一度押すとその枠自体を削除します。

    初期表示は文献値にもとづく表示例です（出典は各枠のタイトルに併記、全消去 で白紙になります）。t95%・t99% は残存率 [C]/[C]0 がそれぞれ 5 %・1 % に達する時刻（＝95 %・99 %が消失する時刻）、曲線は t99% まで描画。データはこのブラウザに自動保存されます。

    Example data on first load. Curves are drawn to 99 % loss; state is saved in this browser.

    アレニウスプロットのタブでは、最小二乗法で ln k 対 1/T を回帰し、傾き −Ea/R と切片 ln A から Ea と A を求めます（R = 8.314462618 J mol⁻¹ K⁻¹、T(K) = T(°C) + 273.15）。A の単位は入力した kobs と同じです。

    本シミュレーターは教育・学習を目的として作成したものです。理想的な擬一次条件（kobs 一定・単一経路）を仮定した計算であり、実際の反応系への適用にあたっては実測データによる検証を行ってください。

    This simulator is intended for teaching and self-study. It assumes ideal pseudo-first-order behaviour (a single pathway with constant kobs); validate against measured data before applying it to a real system.
